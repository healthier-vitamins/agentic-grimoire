# Scope

Choose the questions when the user names a test instead of handing them over.

1. **Find the scope.** Read the course's own announcement of which sections the test covers. A later announcement from the lecturer overrides the slides.
2. **Find the template.** The template is the latest problem-solving sheet (or practice set) before the test. Check each past test in the course against the sheet that came before it; when each one followed its sheet, treat this sheet as the template.
3. **Map the questions.** List every in-scope tutorial question, and every past-exam question, against the template's skills.
4. **Offer the full list** — every in-scope question, template questions first. When the user asks for a shorter set, cut it to the template questions, the one or two questions closest to each template skill, and one question per in-scope skill the template leaves out.

**Done when:** every in-scope section has at least one question, every question has a solution source or is flagged as having none, and the user has confirmed the list.
